# Providers

Hatchery supports BYOAK-style setup for OpenAI, Anthropic, Google Gemini, Groq, Perplexity Sonar, xAI/Grok, DeepSeek, Kimi, Ollama, and LM Studio. Provider manifests declare supported auth methods (`api_key`, `oauth`, `cli`, `local`), model capabilities, cost metadata, routing hints, and failover.
