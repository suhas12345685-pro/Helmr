# Helmr

Helmr is a self-hosted, TypeScript-first AI orchestration system.

## Install Helmr

You can install Helmr using one-liners or via npm/pnpm.

### Option 1: One-liners

**Windows (PowerShell)**
```powershell
powershell -c "irm https://helmr.ai/install.ps1 | iex"
```

**macOS and Linux**
```bash
curl -fsSL https://helmr.ai/install.sh | bash
```

### Option 2: npm / pnpm

```bash
npm i -g helmr
# or
pnpm i -g helmr
```
